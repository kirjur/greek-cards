## Алфавит

| Буква | Название | Звук |
|---|---|---|
| Α α | άλφα | [а] |
| Β β | βήτα | [в] |
| Γ γ | γάμμα | [ɣ] — мягкое фрикативное «г»; перед [э], [и] → [й] |
| Δ δ | δέλτα | [ð] — как *th* в *this*, язык между зубами |
| Ε ε | έψιλον | [э] |
| Ζ ζ | ζήτα | [з] |
| Η η | ήτα | [и] |
| Θ θ | θήτα | [θ] — как *th* в *think* |
| Ι ι | γιώτα | [и] |
| Κ κ | κάπα | [к] |
| Λ λ | λάμδα | [л] |
| Μ μ | μι | [м] |
| Ν ν | νι | [н] |
| Ξ ξ | ξι | [кс] |
| Ο ο | όμικρον | [о] |
| Π π | πι | [п] |
| Ρ ρ | ρο | [р] |
| Σ σ ς | σίγμα | [с]; ς — только в конце слова |
| Τ τ | ταυ | [т] |
| Υ υ | ύψιλον | [и] |
| Φ φ | φι | [ф] |
| Χ χ | χι | [х] |
| Ψ ψ | ψι | [пс] |
| Ω ω | ωμέγα | [о] |

Звук [и] пишется пятью способами: **ι, η, υ, ει, οι**. [о] — двумя: **ο, ω**. [э] — двумя: **ε, αι**.

Внимательно с θ, δ, σ, ζ и ντ — это пять разных звуков.

## Сочетания гласных

| Пишем | Читаем | Пример |
|---|---|---|
| ου | [у] | φούρνος, πουλί |
| αι | [э] | καιρός, παιδί |
| ει | [и] | κλείνω, σειρά |
| οι | [и] | φίλοι, ανοίγω |

## Дифтонги: безударный [и] + гласный

Если над [и] (ι, ει, οι, υ — кроме η) нет ударения и после него идёт гласный, [и] превращается в [й]:

- ια, εια, οια → [йа] (я): παιδιά [пеðЯ], δουλειά
- ιο, ειο → [йо] (ё): ποιος
- ιε → [йэ] (е)
- ιου → [йу] (ю)

Если перед таким сочетанием стоит **γ**, она не читается: για [йа], γιος [йос], γιατρός, γιαγιά [йайЯ].

## Ударение — граница слога

Буква с ударением закрывает слог: всё до неё (включая её) сливаем по правилам, после неё начинается новый слог.

- Ударение на **последнем** элементе сочетания → сливаем: αί [э], ειά [йа], ιού [йу].
- Ударение на **первом** элементе → читаем раздельно: άι [аи], όι [ои], ία [иа], ίο [ио].
- ρόλοι [рОли] — роли, но ρολόι [ролОи] — часы. Одни и те же буквы, разное ударение.
- μαγιά [майЯ] — дрожжи, но μαγεία [майИа] — магия.
- Παναγία [панайИа] — книжный вариант, Παναγιά [панайЯ] — разговорный.
- В словах из нескольких слогов ударение ставим **всегда**. Нет ударения — значит, слог один.
- γ исчезает только перед безударным [и] + гласный. Если [и] ударный, γ звучит: μαγεία.

Длинные сочетания сливаем слева направо, пока получается один слог: εια → [йа], ιου → [йу].

## αυ и ευ

Второй элемент превращается в согласный:

- перед гласной или звонкой согласной (β γ δ ζ λ μ ν ρ) → **[ав] / [эв]**: αύριο [Аврио], αυγή [авйИ], Ευρώπη [эврОпи];
- перед глухой согласной (θ κ ξ π σ τ φ χ ψ) → **[аф] / [эф]**: αυτό [афтО], ευχαριστώ [эфхаристО], ευθύνη [эфθИни].

Ударение пишется над второй буквой (αύ, εύ), хотя ударный звук — первый.

## Согласные сочетания

| | В начале слова и в иностранных словах | В середине греческого слова |
|---|---|---|
| μπ | [б]: μπορώ, μπράβο, ομπρέλα | [мб]: αμπέλι, λάμπα |
| ντ | [д]: ντομάτα, ντοκιμαντέρ | [нд]: κοντά, δόντια |
| γκ | [г]: γκολ, γκρι, Γκάντι | [нг]: όγκος |
| γγ | — | [нг]: αγγούρι, φεγγάρι |
| γχ | — | [нх]: ελέγχω, σύγχρονος |
| τσ | [ц]: τσίρκο, ράτσα | |
| τζ | [дз]: τζάκι, ατζέντα | |

Исключение: в детских и звукоподражательных словах одинаковые слоги читаются одинаково: μπαμπάς [бабАс] — папа, νταντά [дадА] — няня.

Греческие слова заканчиваются только на гласную, **-ς** или **-ν**. Другое окончание — значит, слово заимствованное.

На Кипре μπ/ντ в середине звучат с носовым призвуком, τσ — как [ч], τζ — как [дж]. Ориентируемся на афинскую норму (она на экзамене).

## Озвончение

- σ перед звонкой согласной → [з]: κόσμος [кОзмос], Ισραήλ [израИл], σβήνω [звИно]. На стыке слов тоже: ο φίλος μου [фИлоз му].
- ν на конце + глухая в начале следующего слова (в беглой речи): τον Κώστα [тон гОста], δεν ξέρω [ðэн гзЕро].
- Гласные в разговоре проглатывают: εντάξει → ντάξει [дАкси].
