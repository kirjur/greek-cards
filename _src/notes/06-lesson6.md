## Как назвать своё имя

| Конструкция | Стиль | Имя |
|---|---|---|
| **Λέγομαι** Κώστας Κανάκης. | официально (учреждение, врач, собеседование) | именительный падеж, без артикля |
| **Με λένε** Κώστα Κανάκη. | нейтрально, уместно везде | винительный падеж, без артикля |
| **Είμαι ο** Κώστας. / **Είμαι η** Μαρία. | дружески, «я такой-то» | с артиклем |

- **Με λένε** — «меня зовут» (букв. «меня называют»). Подлежащее — «они», люди, которых не произносим, поэтому имя стоит в винительном падеже.
  - Мужские греческие имена теряют -ς: Γιάννης → Με λένε **Γιάννη**, Πέτρος → **Πέτρο**. Как по-русски «меня зовут Петром».
  - Женские не меняются: Με λένε Μαρία, Ελένη Παυλίδη.
  - Иностранные имена без -ς не меняются: Με λένε Ιβάν, Κίριλ. А если выбрал греческую форму (Κύριλλος) — подчиняйся грамматике: Με λένε Κύριλλο.
- После «зваться / называться» артикль не ставится: имя слишком тесно связано с глаголом. С είμαι — наоборот, ставится: имя — самая уникальная характеристика человека. Остальные характеристики (профессия и т. п.) — без артикля.
- Важно слышать изменённую форму, чтобы потом не говорить «я встретил вчера Петро».

## Переброс вопроса

| | на «ты» | на «вы» |
|---|---|---|
| Как тебя / вас зовут? | Πώς **σε** λένε; | Πώς **σας** λένε; |
| А тебя / а вас? | **Εσένα;** | **Εσάς;** |

σε / σας — короткие формы, живут только рядом с глаголом и своего ударения не имеют. Без глагола им нужно «отрастить лапки» → εσένα, εσάς.

```dialog
Πέτρος Δήμας: Πώς σας λένε; | Как вас зовут?
Κάρμεν Μοράλες: Με λένε Κάρμεν Μοράλες. Εσάς; | Меня зовут Кармен Моралес. А вас?
Πέτρος Δήμας: Με λένε Πέτρο Δήμα. | Меня зовут Петрос Димас.
Κάρμεν Μοράλες: Χαίρω πολύ. | Очень приятно.
Πέτρος Δήμας: Κι εγώ. | Мне тоже.
```

```dialog
Κατερίνα: Πώς σε λένε; | Как тебя зовут?
Πέτρος: Με λένε Πέτρο. Εσένα; | Меня зовут Петрос. А тебя?
Κατερίνα: Με λένε Κατερίνα. | Меня зовут Катерина.
```

Ещё два мини-диалога из учебника:

```dialog
Κώστας Κανάκης: Γεια σας. Λέγομαι Κώστας Κανάκης. | Здравствуйте. Меня зовут Костас Канакис.
Λόρα Γκριν: Χαίρω πολύ. Λόρα Γκριν. | Очень приятно. Лора Грин.
Κώστας Κανάκης: Χαίρω πολύ. | Очень приятно.
```

```dialog
Μόνικα: Γεια σου. Με λένε Μόνικα. | Привет. Меня зовут Моника.
Γιάννης: Γεια σου, Μόνικα. Με λένε Γιάννη. | Привет, Моника. Меня зовут Янис.
```

Уже знакомый набор: εσύ — ты, σου — тебе, σε — тебя. Разберём подробно на уровне Β.

## Приветствия и прощания

| | Когда | Заметки |
|---|---|---|
| **Γεια σας** | привет и пока, на «вы» | букв. «здоровья вам», любое время суток |
| **Γεια σου / Γεια** | привет и пока, на «ты» | σου — «тебе». Не «γεια σας»! |
| **Καλημέρα (σας / σου)** | с рассвета | μέρα — **день**, не «утро» |
| **Καλησπέρα (σας / σου)** | когда темнеет | на Кипре — уже с полудня |
| **Χαίρετε** | привет и пока, максимально официально | букв. «радуйтесь»; только на «вы» |
| **Αντίο (σας)** | до свидания | на Кипре звучит как «прощайте» |
| **Καληνύχτα (σας / σου)** | спокойной ночи | только прощание; νύχτα — ночь |
| **Χαίρω πολύ** | приятно познакомиться | только при знакомстве, «радуюсь очень» |
| **Χάρηκα** | было приятно познакомиться | чаще в конце разговора |
| **Κι εγώ** | и я | κι = και перед гласной |

## Род по окончанию

| Артикль | Окончание | Пример |
|---|---|---|
| **ο** (м. р.) | -ος | ο Πέτρος, ο φίλος |
| | -ας | ο Κώστας |
| | -ης | ο Γιάννης, ο φοιτητής |
| **η** (ж. р.) | -α | η Μαρία, η Αθήνα |
| | -η | η Ελένη |
| **το** (ср. р.) | -ο | το μήλο, το αεροπλάνο |
| | -ι | το παιδί, το σπίτι |
| | -μα | το μάθημα, το πρόβλημα |

- Это базовые типы склонения для А1–А2, в языке их больше. Три мужских типа (-ος, -ας, -ης) склоняются по-разному, как русские «стол», «конь», «папа».
- **-α → женский, но -μα → средний!** Исключения с -μα: иностранные слова (η φόρμα, η πλατφόρμα, η κρέμα, η φίρμα) и η μαμά.
- На -ος бывают слова женского рода: η Κύπρος, η Λεμεσός — запоминаем отдельно. По умолчанию -ος → мужской.
- Конец -ι с йотой (ι) — средний род, -η с итой (η) — женский.
- Совпадение с русским родом — случайность (το μήλο — яблоко).

## Падежи: именительный и винительный

**Именительный** — кто? что? Тот, кто действует: **Η γάτα** τρώει — кошка ест. Обычно в начале фразы.

**Винительный** — два главных случая:

1. **Глагол + винительный** — объект действия, вопрос «кого? что?»: вижу кошку; мама мыла **раму**.
2. **Предлог + винительный** — после предлога **всегда** винительный. Вопрос не задаём, вырабатываем рефлекс. Творительного падежа в греческом нет.

## Предлоги (+ винительный)

| Предлог | Значения |
|---|---|
| **από** | из, от (from): из России, письмо от Петра |
| **με** | с (with): живу с Петром; на (транспорте): на машине; с помощью: копаю лопатой |
| **για** | для (for): цветы для Петра; за (цель): пошёл за кофе; про (about): говорю про Петра |
| **σε** | в, на, к, у — где? и куда?: в школе и в школу — одно и то же |

**σε сливается с артиклем винительного падежа:**

- σε + τον = **στον** (м. р.)
- σε + την = **στην** (ж. р.): στην ταβέρνα — в таверне
- σε + το = **στο** (ср. р.): στο μουσείο — в музее

В женском и среднем роде существительное в винительном не меняется, в мужском — меняется (разберём на следующем уроке).
